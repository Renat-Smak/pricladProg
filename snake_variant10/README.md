# Лабораторная работа №10 — «Змейка» (вариант 10)

Консольная игра «Змейка» на C++20. Проект реализует требуемые методическими указаниями поведенческие паттерны **Observer (Наблюдатель)** и **State (Состояние)**.

## Возможности
- игровое поле с границами, змейкой и едой;
- управление WASD, пошаговое движение пробелом;
- начисление 10 очков за еду;
- обнаружение столкновений со стенами и телом;
- меню, игровой процесс, пауза, конец игры и повторный запуск;
- уведомление подписчиков об изменении состояния, счёта, поедании еды и столкновении;
- автоматические тесты логики и переходов состояний.

## Требования
- CMake 3.20 или новее;
- компилятор с поддержкой C++20 (GCC 10+, Clang 10+, MSVC 2019+).
- Внешние библиотеки не требуются.

## Сборка и запуск

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build --output-on-failure
```

Запуск:
- Linux/macOS: `./build/snake_game`
- Windows: `build\\Release\\snake_game.exe` (Visual Studio) или `build\\snake_game.exe` (MinGW)

В меню нажмите Enter. Во время игры: `W/A/S/D` — изменить направление и выполнить ход, пробел — выполнить ход в текущем направлении, `P` — пауза, `Q` — выход. После проигрыша `R` начинает новую игру.

> Это пошаговая консольная реализация: каждый ввод направления выполняет один игровой ход. Такой режим не требует графических библиотек и одинаково собирается на Windows и Linux.

## Реализация паттернов

### Observer — Наблюдатель
`Subject` хранит подписчиков `Observer`. Класс `Game` наследует `Subject` и рассылает `GameEvent` при изменении состояния, счёта, поедании еды и столкновении. `ConsoleObserver` подписывается на события и получает сообщения, не связывая игровую модель напрямую с выводом.

### State — Состояние
`GameController` делегирует обработку команд текущему объекту `GameState`. Конкретные состояния: `MenuState`, `PlayingState`, `PausedState`, `GameOverState`. Переходы заменяют объект состояния, поэтому поведение клавиш зависит от текущего состояния и не реализовано одним большим набором условных операторов.

## Структура

```text
include/snake/game.hpp  — модель, Observer/Subject и интерфейс State
src/game.cpp            — игровая логика и уведомления наблюдателей
src/states.cpp          — конкретные состояния и контроллер
src/main.cpp            — консольный интерфейс и наблюдатель
 tests/tests.cpp        — автоматические проверки
 docs/class_diagram.puml — UML-диаграмма классов (PlantUML)
```

## Проверки
Тесты проверяют старт игры, движение змейки, уведомления Observer, переходы «Меню → Игра → Пауза → Игра» и завершение при столкновении со стеной. Команда `ctest` запускает их после сборки.

## Графическая демонстрационная версия

Для демонстрации игры без установки компилятора откройте `game.html` в любом современном браузере (Chrome, Edge, Firefox). В Windows можно дважды нажать `Открыть_игру.bat`.

Управление: WASD или стрелки — направление; пробел — пауза/продолжить; R — новая игра; Enter — начать. Рекорд сохраняется в локальном хранилище браузера. Графическая версия автономная и не требует интернета или установки библиотек. В её JavaScript также показаны Observer (EventBus) и State (MenuState, PlayingState, PausedState, GameOverState). Основная реализация лабораторной работы на C++20 находится в `src/`.
