## 1. Цель работы
Получить практические навыки применения поведенческих паттернов проектирования «Наблюдатель» (Observer) и «Состояние» (State) при разработке программного приложения.

## 2. Постановка задачи
Согласно методическим указаниям «Паттерны проектирования», вариант 10 — приложение «Игра „Змейка“». Для лабораторной работы №10 требуется реализовать прикладную задачу с использованием паттернов «Наблюдатель» и «Состояние».

## 3. Средства разработки
Язык C++20, система сборки CMake 3.20+, стандартная библиотека C++. Внешние зависимости отсутствуют.

## 4. Описание приложения
Разработана пошаговая консольная игра. Игровое поле ограничено стенами. Игрок управляет змейкой клавишами W, A, S, D. Пробел выполняет ход в текущем направлении. За подбор еды начисляется 10 очков и увеличивается длина змейки. Столкновение со стеной или собственным телом завершает игру. Предусмотрены меню, пауза, экран окончания и повторный запуск.

## 5. Применение паттернов проектирования

### 5.1. Наблюдатель (Observer)
Паттерн реализован базовыми классами `Subject` и `Observer`. `Game` выступает издателем событий и уведомляет подписчиков через `notify`. Наблюдатель `ConsoleObserver` принимает события и обновляет сообщение интерфейса. События включают изменение состояния игры, изменение счёта, поедание еды и столкновение. Благодаря этому игровая модель не зависит от конкретного способа отображения уведомлений.

### 5.2. Состояние (State)
Интерфейс `GameState` определяет обработку команды и получение текущего состояния. Реализованы `MenuState`, `PlayingState`, `PausedState` и `GameOverState`. `GameController` хранит текущее состояние и передаёт ему пользовательские команды. Каждое состояние задаёт собственное допустимое поведение клавиш; при переходе контроллер заменяет объект состояния.

## 6. Структура проекта
- `include/snake/game.hpp` — объявления модели, событий, интерфейсов Observer и State;
- `src/game.cpp` — логика движения, столкновений, еды и уведомлений;
- `src/states.cpp` — реализации конкретных состояний и контроллера;
- `src/main.cpp` — консольный интерфейс и подписчик событий;
- `tests/tests.cpp` — автоматические тесты;
- `docs/class_diagram.puml` — UML-диаграмма классов.

## 7. Тестирование
Автоматические тесты проверяют запуск игры, начальную длину змейки, движение, получение уведомлений подписчиком, переходы между меню, игрой и паузой, а также завершение игры при столкновении со стеной. Для запуска тестирования используется CTest: `ctest --test-dir build --output-on-failure`.

## 8. Инструкция по сборке и запуску
```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build --output-on-failure
./build/snake_game
```

## 9. Вывод
В ходе лабораторной работы разработана игра «Змейка» (вариант 10) на C++20. В проекте применены паттерны Observer и State: первый обеспечивает оповещение подписчиков о событиях игровой модели, второй инкапсулирует поведение игровых режимов. Проект собирается средствами CMake и содержит автоматические тесты основных сценариев.
